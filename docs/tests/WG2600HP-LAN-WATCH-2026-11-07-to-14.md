## 2. 集計結果

| 指標 | LANゲートウェイ `192.168.10.1` | 外部IPv4 `1.1.1.1` |
| --- | ---: | ---: |
| 観測された送信シーケンス | 548,162 | 559,486 |
| 応答あり | 547,978 | 558,999 |
| 応答なし | **184** | **487** |
| 観測中の応答なし率 | **0.03357%** | **0.08704%** |
| 成功応答時の平均RTT | 0.645 ms | 17.815 ms |
| 成功応答時の最大RTT | 10.4 ms | 431 ms |
| うち11/13停電直前の連続応答なし | 175 | 175 |

計数方法:
- 4回のpingプロセス実行区間を独立に扱い、`icmp_seq` の16ビット循環を補正。
- `no answer yet for icmp_seq=...` と実際に欠けた応答シーケンスの数が一致した。
- **損失率はログが記録されたping送信に限る**。監視自体が停止した期間の送信数を推定しない。
- `Destination Host Unreachable` などは別の失敗パケットとして二重計上しない。
- 外部宛pingの無応答には、遠隔宛先側でのICMP制限等の可能性も含まれる。
  すべてをルーター起因と断定しない。

補助値として、**11/13の停電直前の各175送信を除外した場合**:
- LAN: 9 / 547,987 = **0.00164%**
- 外部IPv4: 312 / 559,311 = **0.05578%**

これは「停電起因の175件」とそれ以外を区別するための参考値であり、
停電直前に実際に観測された通信断を消去するものではない。

- **欠測時間合計は約12時間22分41秒**、168時間の約7.37%。
- ログ時刻の範囲で見た観測カバー率は概算 **92.63%**。
- この比率はログ取得期間のカバー率であり、**ネットワーク稼働率ではない**。
- ログ再開時刻は再通電時刻と必ずしも一致しない。
- `ubuntu-kernel.log` は11/13 14:09:44の監視再開時に追加されたため全期間を網羅しない。
- 停電時の通信不能と、監視停止中の未知の状態を区別すること。

## 5. 実際に確認された通信・リンクイベント

### 5.1 11月9日15:52：外部IPv4のみ連続無応答

- `internet-v4.log` に **22送信連続の無応答**（15:52:21〜15:52:42）。
- 同時間帯の `gateway.log` ではゲートウェイ応答が継続。
- **LAN全体のリンク断とは区別できる**が、WANトンネル、上流、遠隔宛先のどこが原因かは未特定。

### 5.2 11月11日：Ubuntu有線LANのキャリア消失を2回確認

`eno1-link.log` の `NO-CARRIER` / `LOWER_UP` 記録:

| キャリア消失（JST） | 回復（JST） | 確認された断時間 |
| --- | --- | ---: |
| 11:43:18.828 | 11:43:21.576 | 約2.75秒 |
| 11:46:34.502 | 11:46:37.770 | 約3.27秒 |

この2件はLAN pingと外部IPv4 ping双方の応答欠落および
`Destination Host Unreachable` と時間帯が一致する。
**少なくとも2回、Ubuntu側の有線リンクが実際にDOWNになった事実は確認できる**。
ただしルーターの物理ポート、ケーブル、Ubuntu NICのどれが根本原因かは未特定。

### 5.3 11月13日：停電に先立つ断続的なキャリア消失

`eno1-link.log` では以下を記録:

- 13:22:08 DOWN → 13:22:21 UP（約13.54秒）
- 13:22:25 DOWN → 13:22:28 UP（約3.35秒）
- 13:22:50 DOWN → 13:22:53 UP（約3.28秒）
- 13:23:23 DOWN → **監視停止前にUP記録なし**
- 13:22:09ごろからLANと外部IPv4のpingが共に無応答。
- 両pingに**175件ずつの連続無応答**（13:22:09〜13:25:07付近）。
- SSHも13:22以降切断し、`Network is unreachable` を複数記録。
- 14:09:44に復電後の監視再開記録。

これは停電前後の系統的な接続喪失を示す。
個々の瞬断をルーターファームの不具合として数えることはしない。
